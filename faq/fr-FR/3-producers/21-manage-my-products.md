## Qu'est-ce qui garantit la qualité des données dans Open Food Facts ?

**Pour améliorer continuellement la qualité des données, nous nous appuyons sur 4 piliers :**

1. La communauté ajoute constamment des données et des photos et constitue une véritable patrouille de relecteurs.

2. Nous avons mis en place des règles logiques pour identifier les erreurs sur les fiches produits.Par exemple : si la somme du poids des ingrédients est supérieure au poids total du produit, il y a une anomalie. Nous avons environ 50 autres contrôles qualité.

3. Grâce au Machine Learning, nous limitons le risque d'erreurs de saisie. Notre technologie nous permet d'extraire des données textuelles à partir de photos prises par les contributeurs.

4. Grâce au soutien de Santé Publique France, nous avons développé un portail permettant aux producteurs de télécharger leurs données en masse et ainsi de corriger/compléter les contributions de la communauté.

## Comment ajouter des produits ?

Pour ajouter des produits sur notre plateforme, vous devez d'abord décider de la méthode que vous souhaitez utiliser. Il existe 4 options :

- **Manuellement** : si vous avez un petit nombre de produits, il est toujours possible de créer chaque fiche produit à la main sur la Plateforme Pro.

- **Via une importation de feuille de calcul** : vous pouvez télécharger le [modèle](https://world.pro.openfoodfacts.org/cgi/generate_sample_import_file.pl) fourni par Open Food Facts, ou importer directement une extraction de votre système informatique sur la plateforme Pro.

- **Via les connecteurs de catalogues produits**. Si vous êtes client chez EQUADIS, AGENA3000 ou BAYARD, vous pouvez télécharger vos données sur Open Food Facts en 1 clic. Si vous travaillez avec un autre PIM (Product Information Management), veuillez nous contacter : producers@openfoodfacts.org

- **Via une connexion sur mesure** entre votre entreprise et Open Food Facts. Si vous comptez plus de 1000 produits dans votre portefeuille, nous pouvons discuter de l'opportunité de construire un connecteur spécifique pour faciliter le transfert de données.

Pour plus de détails, nous vous invitons à télécharger notre [guide utilisateur](https://blog.openfoodfacts.org/en/EN-Pro-Plateform-User-Guide.pdf) et/ou à consulter nos [tutoriels vidéo](https://www.youtube.com/playlist?list=PLjAH-USadsF3xgSVfUUBS4we3XBr-1r55) :-)

## Le nombre de produits ajoutés est-il limité ?

Il n'y a aucune limite, vous pouvez télécharger le nombre de produits que vous souhaitez sur notre plateforme.

---

## Est-il possible de supprimer des produits qui ne sont plus vendus ?

Si vous souhaitez supprimer un produit qui n'est plus disponible sur le marché, il vous suffit de cocher la case "ce produit n'est plus commercialisé" lors de l'édition de votre fiche produit.

Si vous souhaitez supprimer plusieurs produits, nous vous recommandons de suivre la procédure mentionnée dans le [guide utilisateur](https://blog.openfoodfacts.org/en/EN-Pro-Platform-User-Guide.pdf), en page 18.

Vous pouvez également nous contacter via producers@openfoodfacts.org si vous avez des questions.

Lorsque le produit est archivé, il n'apparaîtra plus dans Open Food Facts.Il restera cependant dans notre base de données afin que nous puissions conserver un historique des produits vendus au fil du temps.

## Les informations de l'entreprise prévalent-elles sur les informations déjà présentes sur la plateforme ?

Lorsqu'un producteur met en ligne l'un de ses produits avec son compte producteur et qu'une fiche produit existe déjà, cela la complétera.

Les informations que le producteur aura publiées seront toujours prioritaires et lui seul pourra modifier ses produits lorsque les informations sont renseignées.

Si les données envoyées via la plateforme sont fragmentées, les informations ajoutées par la communauté à partir de l'emballage peuvent les compléter.

## Dans quel format dois-je envoyer mes données ?

Un [modèle](https://world.pro.openfoodfacts.org/cgi/generate_sample_import_file.pl) est fourni par Open Food Facts.

Cependant, tout format de feuille de calcul (xlsx, csv) sera importable sur la plateforme.  
Notre algorithme est conçu pour faire correspondre automatiquement les attributs de votre fichier avec ceux présents dans Open Food Facts. Veillez à toujours vérifier l'étape de correspondance, car vous pourriez avoir besoin d'en ajuster manuellement certaines.

Si vos informations sont fragmentées entre plusieurs feuilles de calcul, vous pouvez les importer consécutivement - en vous assurant d'effectuer la correspondance si le format change.

Vous pouvez également importer un fichier Excel en complément d'un import EQUADIS ou AGENA3000, si les données ne sont pas encore dans votre système d'information. Dans ces cas-là, n'oubliez pas de demander une exportation vers la base de données publique depuis l'interface.

## Comment ajouter des produits sans code-barres via la plateforme Pro ?

Pour les produits sans code-barres, sur le site ou sur la plateforme producteur, il existe un bouton "Produit sans code-barres" dans la colonne de gauche qui vous permet de les ajouter. Un identifiant est alors généré automatiquement.

## Les données produits de mon entreprise sont disponibles sur Open Food Facts. Est-il possible de prendre le contrôle du compte producteur associé ?

Oui, bien sûr ! Vous pouvez prendre le contrôle du compte producteur associé en créant un compte Open Food Facts avec votre adresse professionnelle. Lors de votre inscription, mentionnez le nom de l'organisation présente sur la fiche pour pouvoir accéder à l'espace producteur correspondant.

Une courte étape de validation sera nécessaire pour garantir que vous êtes bien le producteur.

Vous pourrez compléter les données, ajouter des images, obtenir des recommandations automatiques pour améliorer le Nutri-Score, et bien plus encore. Tout cela est bien entendu entièrement gratuit. Vous pouvez également connecter un système de gestion de données produit tiers tel qu'EQUADIS, AGENA3000 et Bayard consulting.

→ Pour plus de détails, nous vous invitons à télécharger notre [guide utilisateur](https://blog.openfoodfacts.org/en/EN-Pro-Plateform-User-Guide.pdf) et/ou à consulter nos [tutoriels vidéo](https://www.youtube.com/playlist?list=PLjAH-USadsF3xgSVfUUBS4we3XBr-1r55) :-)

## Combien de temps faut-il pour que les données des producteurs soient mises à jour sur les autres applications utilisant la base de données Open Food Facts ?

Cela dépend des applications. Pour celles qui utilisent nos API, ce qui représente la grande majorité, c'est immédiat.  
Pour celles qui utilisent nos exports quotidiens, c'est à J+1, à condition qu'elles effectuent la mise à jour.

## L'importation des données d'une fiche produit complète-t-elle ou écrase-t-elle la fiche produit existante ?

Nous utilisons le code-barres pour identifier les produits ; si vous importez une fiche avec le même code-barres qu'une fiche existante, les informations seront fusionnées.

Pour les données telles que la liste des ingrédients ou les valeurs nutritionnelles (une seule valeur correcte possible), les données envoyées via la plateforme producteur écraseront les données existantes.

Pour les données telles que les labels/catégories/marques (plusieurs valeurs correctes possibles), les informations sont fusionnées. Si les données sont incorrectes sur la plateforme publique, vous pouvez modifier la fiche produit sur la plateforme publique pour supprimer les valeurs incorrectes.

→ Pour plus de détails, nous vous invitons à télécharger notre [guide utilisateur](https://blog.openfoodfacts.org/en/EN-Pro-Plateform-User-Guide.pdf) et/ou à consulter nos [tutoriels vidéo](https://www.youtube.com/playlist?list=PLjAH-USadsF3xgSVfUUBS4we3XBr-1r55) :-)

## L'ordre des ingrédients est-il important ?

L'ordre des ingrédients est important : il représente l'ordre par quantité.
La meilleure façon de renseigner les ingrédients est de suivre exactement ce qui est écrit sur l'emballage. C'est pourquoi il est également très important d'avoir des photos des ingrédients imprimés.

## Puis-je également envoyer des images via AGENA3000 ?

Vous pouvez envoyer des images, mais en pratique, seule l'image principale sera sélectionnée automatiquement ; les autres images seront envoyées, mais ne seront pas recadrées / sélectionnées pour les ingrédients, la nutrition, etc.
